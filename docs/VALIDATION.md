## 已验证

- `swift test`：9 项通过，无失败。覆盖主屏及负坐标显示器转换、每屏聚焦、跨屏窗口、同应用多个窗口、没有窗口的前台应用、AX 精确匹配、非法 URL 参数和强度边界。
- `HazeFocus --render-check`：6 项通过。使用真正的 AppKit 绘制代码检查背景 alpha、两个窗口的透明区域、相交透明区域不会反转、上方非聚焦窗口保持正确遮罩浓度，以及遮罩无法获取键盘焦点或拦截点击。
- Release 构建：arm64 和 x86_64 均通过；lipo 确认 Universal 可执行文件含两个架构。
- 打包 `.app` 可启动，中文聚焦、遮罩、快捷键和显示器页面通过截图检查；布局无裁切。
- 全局快捷键录制 UI：录入 ⌃⌥⌘J 后显示正确，恢复默认 ⌃⌥⌘H 成功。
- 最终版本对定向键盘事件 ⌃⌥⌘H 的开关 UI 验证：暂停后开关变为 off，再次按下恢复 on。Carbon 注册成功；从其他应用发出的真实硬件全局按键仍建议用户试按确认。
- AppleScript：设置 intensity=42、enabled=false，读取结果 `false, 42.0`，成功。
- URL：`hazefocus://intensity?value=65` 后读取 `true, 65.0`，成功；最终保留默认开启、65% 状态。
- 本机窗口列表诊断成功，无需申请录屏权限。
- 最终 DMG 通过 `hdiutil verify`，只读挂载后应用、Applications 链接和中文说明齐全；挂载包通过 `codesign --verify --deep --strict`。
- Info.plist 格式校验通过；ZIP 与 DMG 的 SHA-256 已保存至 `artifacts/SHA256SUMS.txt`。
- 辅助功能授权的 UI 正确显示基础模式；未代替用户开启系统权限。
